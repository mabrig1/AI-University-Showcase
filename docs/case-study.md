# Engineering case study

## Problem
Self-paced learners need clear pathways, understandable progress and practical assessments.

## Approach
Separate learning content, progress evidence, access rights and recommendations. Record completion only for known modules; distinguish assessed work from self-reported achievements. The original project documentation describes 63 courses and 20 bounded deterministic task specialists, not live LLM agents. These documented counts are not independently audited here.

## Portfolio evidence
The independent demonstration uses fictional module identifiers and synthetic progress. It has no payment, authentication, private content or real learner records. No accreditation, learning outcome or production availability claims are made.
