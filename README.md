AI University is a membership-based self-paced learning platform, not an accredited university or degree-awarding institution. Its original project documentation describes 63 courses, coding labs, learning pathways and 20 bounded deterministic task specialists. These specialists are not live LLM agents. Product capabilities and counts are documented, not independently audited here.

## Reproduce the example

```sh
python demo/progress.py
python -m unittest discover -s demo -v
```

Python 3.10+; no dependencies or keys. The example demonstrates progress calculation, duplicate handling and validation using synthetic data. It does not award credentials, process payments, use real learner data or invoke AI providers.
